6. Cosa fare se…

  1. Il pannello non si apre in locale: controllare di essere sulla stessa rete. Provare - (su alcuni Android non funziona). Se l'IP e' cambiato, si legge nel router tra i dispositivi collegati, con il nome -.
  2. Da remoto non risponde: provare sia Tailscale sia Raspberry Pi Connect (sezione 3). Poi attendere 10 minuti: la base si riavvia da sola se il sistema si blocca (watchdog, 1 minuto), se il kernel va in errore (10 secondi) o se il chip WiFi si blocca (al massimo una volta ogni 6 ore); i servizi della base fermi ripartono da soli entro 1 minuto.
  3. Ancora niente: sul posto, collegarsi alla rete di emergenza (sezione 2) e aprire http://10.42.0.1/network: la pagina Rete mostra connessioni, temperature e registro eventi.
  4. Neanche la rete di emergenza compare: togliere l'alimentazione, aspettare 10 secondi, ridarla e attendere 2 minuti. Se la base non riparte piu', la scheda SD puo' essersi rovinata (succede dopo molti spegnimenti improvvisi): va riscritta e reinstallata.
  5. La base risponde ma il mountpoint non e' in linea: pagina Rete → Registro eventi. "Ricevitore GNSS senza dati" con pochi satelliti = l'antenna non vede abbastanza cielo. Controllare anche cavo e connettore dell'antenna.
  6. Temperature alte (avviso nella pagina Rete): togliere la base dal sole, dare aria al contenitore. Sopra gli 80 gradi il ricevitore e il chip WiFi si bloccano.

7. Operazioni utili

  1. Aggiornare il software: pagina Rete → "Aggiornamenti del software" mostra la versione installata e se ce n'e' una nuova (canale stabile o prova). Per installarla: Settings → Check update → Update (alcuni minuti, la base si ferma). Senza internet: Settings?update=manual e caricare un install.sh di EVONETRTKBASE. Prima di ogni aggiornamento la base salva una copia di sicurezza in /usr/local/rtkbase/backup.
  2. Cambiare le password: pannello → Settings (password del pannello); in SSH il comando passwd (utente); pagina Rete → Hotspot (rete di emergenza); Settings → NTRIP A (caster). Poi ristampare questa scheda.
  3. Salvare le impostazioni di rete: pagina Rete → Esporta (il file contiene password: custodirlo).
  4. Riavviare a distanza: pannello → Settings → Reboot, oppure in SSH sudo reboot.
